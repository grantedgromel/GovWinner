# Buy-Box

The explicit criteria that define what GovWinner will and won't pursue. **Fill this in before bidding on anything.** A tight buy-box is what lets the screening funnel run on autopilot — every gate in [screening-plan.md](screening-plan.md) references these numbers.

Revisit after every ~10 deals using the Stage 9 outcome log.
